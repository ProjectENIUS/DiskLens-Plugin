## 1. Аккаунт

- [ ] Откройте https://hangar.papermc.io и войдите. Вход идёт через аккаунт PaperMC (создайте его там, если нет) [предположение].

## 2. Создание проекта

- [ ] Нажмите «New project» (создать проект).
- [ ] Owner: ваш профиль. Name: `DiskLens` (3-28 символов, только буквы/цифры/`-`/`_`, без слов «Paper» и версий) [проверено].
- [ ] Category: **Admin Tools** [проверено, что значение существует].
- [ ] Summary (до 120 символов) [проверено]: `See which server folders eat your disk: size-sorted tree in chat, console, panel and RCON.`
- [ ] License: MIT (до 20 символов). Если нет в списке, выберите Other и впишите `MIT` [предположение].
- [ ] Keywords (до 5, каждое до 16 символов) [проверено]: `disk`, `storage`, `diskusage`, `folia`, `admin`. Если есть список тегов, отметьте «Supports Folia» [предположение].
- [ ] Сохраните проект. Он создаётся с каналом `Release` по умолчанию [проверено].

- [ ] Вставьте содержимое `description.md` целиком (лимит 75 000 символов, у нас намного меньше) [проверено].
- [ ] Проверьте предпросмотр: таблицы, блоки кода, пример вывода.
- [ ] Заполните ссылки: источники, issues, Discord (плейсхолдеры в `metadata.md`). Реклама запрещена, ссылки на документацию и исходники разрешены [проверено].
- [ ] Поля Donation и Sponsors оставьте пустыми.

## 4. Иконка и скриншоты

Иконка: квадратный PNG 512x512, например лупа над диском/папкой на тёмном фоне. Без логотипов Minecraft и Mojang.

Предложенные скриншоты (на тестовом сервере, названия папок нейтральные, без реальных имён вашего сервера):

1. Игровой чат: `/du` с цветным деревом и кликабельными папками (красный ≥50 %, оранжевый ≥20 %, жёлтый ≥5 %).
2. Чат после клика по папке: кнопки `[↑ up]`, `[Rescan]`, `[Report to file]`.
3. Консоль хостинга: ASCII-дерево `disklens`.
4. `/du files 10`: самые большие файлы.
5. Экспортированный отчёт в текстовом редакторе.
6. Русская локализация в чате (английский клиент рядом для сравнения).

- [ ] Загрузите иконку и вставьте скриншоты в описание как картинки (если Hangar не хостит картинки сам [предположение], залейте на Imgur/GitHub и подставьте ссылки `![alt](url)`).

- [ ] Платформа: **Paper** (Folia отдельной платформой не нашёл, она идёт через Paper + `folia-supported: true`) [предположение, на Hangar платформы Paper/Velocity/Waterfall подтверждены]. Отметьте только версии Minecraft с PASS.

## 6. Заметки для ревью

Hangar проверяет проекты по правилам https://hangar.papermc.io/guidelines. Что учесть:

- [ ] Название без слов о платформе и версии, оригинальное, не выдаёт себя за проект PaperMC [проверено].
- [ ] Плагин без обфускации, без платных функций и скрытых прав доступа, не удаляет данные: он только читает метаданные файлов и пишет отчёты в `plugins/DiskLens/reports/` [проверено, что такие правила есть].
- [ ] Это ваш собственный плагин DiskUsage под новым именем, не форк чужого. Упомяните в описании при вопросах ревью.
- [ ] Если ревьюер спросит про Folia/Spigot: один jar, `folia-supported: true`, мост Folia загружается только на Folia, остальное совместимо с API Spigot 1.16.5.
- [ ] Не публикуйте лишние версии ради обновления даты [проверено].

## Что я проверил и что нет

**Проверено (19.11.2026):** страница правил Hangar; публичный API валидации (лимиты: название 3-28, summary 120, лицензия 20, до 5 keywords по 16 символов, страница до 75 000, файл до 10 МБ, каналов до 5, версия до 32); платформы Paper/Velocity/Waterfall; категория `admin_tools` существует.

**Не удалось подтвердить:** полный список категорий и тегов, наличие Folia как отдельной платформы, список лицензий в выпадающем меню, требования к иконке. Это отмечено как [предположение]; сверьтесь с формой на сайте.
