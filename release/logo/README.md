# DiskLens — логотип и иконка

Все исходники — SVG, написанные вручную из плоских фигур (без шрифтов, растровых картинок и чужих знаков). Логотип нарисован с нуля и не использует текстуры или шрифты Minecraft/Mojang.

## Файлы

| Файл | Что это |
|---|---|
| `disklens-icon.svg` | **Главная иконка**, мастер 512×512. Линза над тремя полосками разного размера (папки, отсортированные по размеру). |
| `disklens-icon-512.png` | PNG 512×512 |
| `disklens-icon-400.png` | PNG 400×400 |
| `disklens-icon-256.png` | PNG 256×256 |
| `disklens-icon-128.png` | PNG 128×128 |
| `disklens-icon-96.png` | PNG 96×96 |
| `disklens-banner.svg` | Шапка страницы 1200×300: иконка + слово «DiskLens» и подпись. |
| `disklens-banner.png` | PNG шапки 1200×300 |
| `alt-1.svg` | Альтернатива 1: линза над стопкой дисков (светлая подложка). |
| `alt-2.svg` | Альтернатива 2: пиксельная линза на сетке 16×16 (тёмная подложка). Пиксели зафиксированы в файле. |
| `render.py` | Скрипт пересборки всех PNG из SVG. |

## Концепции

- **Рекомендую `disklens-icon.svg`.** Линза и полоски читаются на 32–96 px, на светлом и тёмном фоне. Сама плитка тёмная со скруглёнными углами, поэтому иконка держит контраст на любом фоне сайта.
- `alt-1.svg` — понятнее как «диск», но мельче детали на 32 px и хуже на тёмном фоне.
- `alt-2.svg` — пиксельный стиль в духе игрового жанра, но на 32 px линза превращается в мозаику. Подходит только для больших размеров.

## Куда загружать

Размеры ниже — то, что сгенерировано в этой папке. Перед загрузкой проверьте требования конкретной платформы: они меняются, и здесь я их не проверял.

- **Modrinth** — иконка проекта: `disklens-icon-512.png`.
- **Hangar** — аватар проекта: `disklens-icon-256.png` (или 512, если поле принимает большой размер).
- **CurseForge** — аватар проекта: `disklens-icon-400.png` (или 512).
- **SpigotMC** — иконка ресурса: `disklens-icon-96.png` (или 128, если поле принимает больше).
- **Шапка сайта / README** — `disklens-banner.png`.

## Как пересобрать PNG

Нужны Python 3 с Pillow и установленный Google Chrome или Microsoft Edge (используется в фоновом режиме для растеризации SVG; ничего не скачивается).

```bash
python render.py
```

Скрипт рисует `disklens-icon.svg` в 1024 px и уменьшает его до всех размеров методом Lanczos, затем рисует `disklens-banner.svg` в 1200×300. Правьте SVG и запускайте скрипт заново.

Если Chrome и Edge не установлены в стандартных путях, поправьте список `BROWSERS` в `render.py`.

## Примечания

- Подпись «Which folders eat your disk» в баннере — временная английская строка. Замените её или удалите, если нужна другая формулировка.
- В баннере используется системный шрифт (Segoe UI, затем Arial). На системах без Segoe UI текст выглядит немного иначе.
- `alt-2.svg` был сгенерирован однократно скриптом на Python по заданной сетке; дальше он редактируется как обычный SVG.
