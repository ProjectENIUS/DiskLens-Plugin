## 1. Аккаунт
- [ ] Зарегистрируйтесь на spigotmc.org, подтвердите e-mail. [A]
- [ ] Для **бесплатных** ресурсов жёстких требований по числу постов/возрасту аккаунта я не подтвердил. Строгие требования (посты, возраст, число бесплатных ресурсов) относятся к **платным** ресурсам [A, по сторонним источникам]. Если форма «Post Resource» недоступна, значит, не хватает прав — смотрите сообщение на странице.
- [ ] Включите 2FA (рекомендуется) [A].

## 2. Что подготовить заранее
- [ ] **Иконка** — квадратная PNG, например 512×512, понятный значок диска/папки [A размеры].
- [ ] **Скриншоты** (2–4) в PNG/JPG: (1) дерево в игровом чате с кликабельными папками, (2) вывод в консоли (ASCII), (3) `/disklens files`, (4) фрагмент `export`-отчёта. **Закройте реальные имена** миров, папок и плагинов вашего сервера (в примере в описании только вымышленные ExampleMap и т. п.).
- [ ] Текст описания: `description.bbcode`. Метаданные: `metadata.md`. Текст обновления: `update-2.0.0.md`.
- [ ] Ссылка на исходники и ники контрибьюторов (placeholders в `metadata.md`).

## 3. Создание ресурса (Resources → Post Resource) [A, порядок полей может отличаться]
- [ ] Категория: **Spigot → Tools and Utilities** [V].
- [ ] Title и Tag line из `metadata.md` (лимиты покажет форма; если не пропускает — используйте короткие варианты).
- [ ] Version: `2.0.0`.
- [ ] Native version: 1.16.5 (или «1.16»). Tested versions: **только PASS** из `summary-final.md` (см. `metadata.md`).
- [ ] Description: вставьте содержимое `description.bbcode`. Проверьте превью: [SPOILER], [CODE], [LIST], [ICODE], вложенный [LIST] в блоке Tested. Если `[CODE=yaml]` или `[ICODE]` не отрисуются — замените на обычный `[CODE]` / `[B]`.
- [ ] Languages: English, Russian. Source code link, Contributors; Donation link — **пусто**.
- [ ] Тип: бесплатный.
- [ ] **Загрузите jar как файл** (Attach file), а не внешней ссылкой на GitHub/диск [A: правило SpigotMC — файл на самом сайте; внешние ссылки для скачивания не допускаются].
- [ ] Иконка и скриншоты.
- [ ] Включите **Discussion/Support** (чтобы работали обсуждение и отзывы) [A].

## 4. Правила ресурса (проверьте глазами)
- [ ] Название честное и по делу: без «best», «#1», версий, спама эмодзи [A].
- [ ] Версии: заявлены только проверенные (PASS). Описание не обещает того, чего нет [A].
- [ ] Нет обфускации, нет скрытых бэкдоров/отправки данных. В описании сказано «no network access, no metrics»: **проверьте по коду, что это верно**, иначе уберите строку FAQ.
- [ ] Нет рекламы сторонних серверов/ресурсов; ссылки только по делу [A].
- [ ] Реальные названия вашего сервера, IP, имена игроков нигде не засветились (описание, скриншоты, jar).
- [ ] Авторство: это ваш плагин, лицензия на исходники указана (если открыты).

## 5. После отправки
- [ ] Новый ресурс может проходить ручную модерацию — подождите, не создавайте дубли [A].
- [ ] Следите за уведомлениями о вопросах в Discussion и на почте.
- [ ] После публикации проверьте: скачивание работает, превью описания корректное, иконка отображается.
- [ ] При изменениях: **Post Resource Update** с новой версией; текст по образцу в `update-2.0.0.md`.

## Известные расхождения, которые стоит поправить в других местах
- Клики/hover в игровом чате автоматикой не проверены (визуальный тест идёт): перед публикацией скриншотов убедитесь сами, что кнопки работают.
- `README.md` в репозитории устарел (написан для DiskUsage 1.1.0, команды `du`, право `diskusage.use`). Описание на SpigotMC написано по `config.yml`, `plugin.yml`, `lang/en.yml`, `build.gradle.kts`.
- Утверждения «Tab-completion», «no network/metrics», «`/disklens:du`» взяты из README/логики Bukkit, а не из исходников — проверьте.
