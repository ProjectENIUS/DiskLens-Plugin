- [ ] Описание должно говорить, что проект делает, без общих слов. [V]
- [ ] Ссылки на донаты, свой сайт или хостинг-баннеры только внизу страницы и небольшие. [V]

## 4. Аватар и скриншоты
- Аватар: PNG, не меньше 400×400, 1:1, не однотонный квадрат, оригинальный (не чужой арт), без WebP (известный баг). [V]
- Идея аватара: лупа над стопкой слоёв-папок или кольцевой диаграммой, на тёмном фоне.
- Скриншоты (вкладка Images, по несколько штук):
  1. Дерево в игровом чате: цветное, кликабельные папки.
  2. Дерево в консоли хостинга: ASCII.
  3. `/disklens files`: список крупнейших файлов.
  4. Кнопки `[↑ up]`, `[Rescan]`, `[Report to file]` под деревом.
  5. Файл отчёта из `export`.
  6. `config.yml` или `/disklens help`.
- **Важно:** на скриншотах не должно быть настоящих названий миров, папок, игроков или IP вашего сервера. Используйте тестовый сервер. Генерируйте общие имена (`world`, `backups`).
